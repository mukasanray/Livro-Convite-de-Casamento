💌 Convite de Casamento Digital
Convite de casamento interativo e responsivo, criado em HTML, com fotos do casal, trilha instrumental de fundo e informações do evento.

Projeto pessoal, desenvolvido para compartilhar com familiares e amigos.

✨ Funcionalidades
Layout responsivo para celular, tablet e computador
Galeria de fotos do casal
Trilha sonora instrumental de fundo
Informações do evento: data, horário, local e confirmação de presença
Carregamento rápido, sem frameworks nem dependências externas

🚀 Como visualizar
Opção 1: no computador
Baixe o projeto clicando em Code > Download ZIP ou clone o repositório:
bash


git clone https://github.com/mukasanray/Livro-Convite-de-Casamento.git
Abra a pasta do projeto.
Dê dois cliques no arquivo index.html.
Opção 2: online com GitHub Pages
Vá em Settings > Pages no repositório.
Em Source, escolha a branch main e a pasta / (root).
Clique em Save. O link ficará disponível em alguns minutos no formato:
text


https://mukasanray.github.io/Livro-Convite-de-Casamento/
✏️ Como personalizar
Edite o arquivo index.html para alterar:

Nomes dos noivos
Data, horário e local da cerimônia e da recepção
Textos, mensagens e links de confirmação de presença
Fotos, substituindo os arquivos de imagem na pasta e mantendo os nomes ou atualizando os caminhos no HTML
Para trocar a música, substitua o arquivo .mp3 e atualize o caminho no index.html.

📦 Observações sobre os arquivos
A trilha sonora tem cerca de 84 MB. O GitHub aceita arquivos desse tamanho, mas recomenda até 50 MB. Para músicas maiores, use arquivos comprimidos ou hospede o áudio em outro serviço.
Antes de publicar o convite na internet, confirme que você tem direito de uso sobre a música e as fotos.
